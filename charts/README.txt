PNG charts appear here when you run the chart scripts.

This folder starts out almost empty on purpose -- the charts in it should be
YOURS, made by your own computer. Run any of these from your Lab02 folder:

    python scripts/08_chart_scatter.py     -> charts/bills_vs_tips.png
    python scripts/09_chart_boxplot.py     -> charts/tips_by_day.png
    python scripts/10_chart_missing.py     -> charts/takings_gaps.png
    python scripts/12_report_for_the_bank.py -> charts/report_bills_by_day.png

If this folder ever goes missing, don't worry -- every chart script builds it
again before it saves anything.
